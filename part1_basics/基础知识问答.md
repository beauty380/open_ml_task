# 一、机器学习 / 深度学习基础知识问答

## 1. 学习率

学习率就是模型每次调整参数时调整多少。

如果学习率太大，模型可能一下子调整过头，导致 Loss 一直波动，甚至训练不成功。如果学习率太小，每次调整的幅度就很小，训练会比较慢。

训练时可以先设置一个学习率，再根据 Loss 的变化进行调整。比如训练前期使用较大的学习率，后期慢慢减小，也可以使用 Adam 这样的优化器来帮助调整参数更新的幅度。

## 2. 损失函数

损失函数就是用来判断模型预测得准不准的，它会计算预测结果和真实结果之间的差距。

训练模型时，我们希望损失越来越小，所以会根据损失来调整模型的参数。

分类和回归使用不同的损失函数，是因为它们要解决的问题不同。分类是判断数据属于哪一类，一般使用交叉熵损失；回归是预测一个具体的数值，一般使用 MSE 或 MAE。

## 3. 过拟合与欠拟合

过拟合就是模型在训练集上表现很好，但是换成没见过的数据后效果就不好了。可以理解为模型把训练数据记得太死，没有真正掌握其中的规律。

可以通过增加数据、使用 Dropout、降低模型复杂度等方法改善。

欠拟合就是模型连训练数据都没有学好，训练集和测试集上的效果都比较差。

可以尝试增加网络层数、增加训练次数或者调整学习率来改善。

## 4. 梯度下降

梯度下降就是一种帮助模型减小损失的方法。模型先计算出参数应该往哪个方向调整，再不断更新参数，让预测结果慢慢变好。

三种方法主要区别在于每次使用多少数据：

- Batch Gradient Descent：每次使用全部训练数据，结果比较稳定，但是计算比较慢。
- SGD：每次只使用一个样本，更新速度快，但容易出现波动。
- Mini-batch Gradient Descent：每次使用一部分数据，兼顾了计算效率和稳定性。

实际训练中比较常用 Mini-batch。

## 5. 前向传播与反向传播

前向传播就是把数据输入神经网络，经过一层层计算，最后得到预测结果。

反向传播就是在得到预测结果之后，根据预测结果和真实结果的差距，计算各个参数需要调整的方向和程度。

我理解前向传播是让模型先做一次预测，反向传播是帮助模型知道哪里需要改进。这样不断重复，模型的预测效果才能慢慢提高。

## 6. 激活函数

激活函数的作用是让神经网络能够学习更复杂的规律。

如果把所有激活函数都去掉，就算网络有很多层，最后也相当于一个线性模型，无法很好地学习复杂的非线性关系。

常见激活函数有：

- ReLU：大于 0 的部分不变，小于 0 的部分变成 0。计算简单，比较常用，但有些神经元可能一直输出 0。
- Sigmoid：把数值变到 0 到 1 之间，常用于二分类，但有时会出现梯度太小的问题。
- Tanh：把数值变到 -1 到 1 之间，输出可以有正有负，但也可能出现梯度太小的问题。

## 7. 梯度消失与梯度爆炸

梯度消失就是模型在反向传播时，梯度越来越小，导致前面一些网络层的参数几乎无法更新。

梯度爆炸则是梯度越来越大，导致参数调整幅度过大，使训练变得不稳定。

这是因为深层网络需要经过很多层来传递梯度，计算过程中可能不断变小或变大。

可以通过使用 ReLU、合理初始化参数、加入残差连接等方法改善。梯度爆炸还可以通过梯度裁剪来缓解。

## 8. Epoch、Batch Size 与 Iteration

Epoch 表示模型把整个训练集学习一遍。

Batch Size 表示每次拿多少个样本进行训练。

Iteration 表示一次训练步骤，通常处理一个 Batch 并更新一次参数。

比如有 1000 个样本，Batch Size 是 100，那么训练一轮需要 10 次 Iteration。

Batch Size 大一些，通常可以更好地利用 GPU，但会占用更多显存。Batch Size 小一些，占用显存更少，但是训练时的波动可能更明显。

所以需要根据电脑性能和训练效果选择合适的大小。

## 9. 优化器

优化器的作用就是根据计算出的梯度来调整模型参数，让 Loss 逐渐减小。

SGD 比较简单，主要根据梯度和学习率更新参数，但是可能需要仔细调整学习率。

Adam 会参考之前的梯度变化，自动调整不同参数的更新幅度，通常训练起来比较方便。

因为不同优化器调整参数的方式不同，所以即使使用相同的数据和模型，最后的训练结果也可能不同。

## 10. 训练集、验证集与测试集

训练集是用来让模型学习的。

验证集是在训练过程中检查模型效果，帮助我们选择合适的参数和模型。

测试集是在模型训练完成后，用来检查模型面对新数据时的表现。

数据泄漏就是模型提前接触到了本来不应该知道的信息，比如把测试集的数据拿去训练，或者提前使用测试集的信息处理训练数据。

这样会让测试结果看起来很好，但模型实际使用时可能没有这么好的效果，所以实验结果就不可信了。

## 11. 正则化

正则化主要是为了防止过拟合，让模型不要把训练数据记得太死。

L1 正则化会对参数的绝对值进行限制，可以让一些不重要的参数变成 0。

L2 正则化会对参数的平方进行限制，避免某些参数变得过大。

Dropout 是在训练时随机让一部分神经元暂时不起作用，让模型不要过度依赖某几个神经元。

这些方法都可以在一定程度上提高模型对新数据的适应能力。

## 12. 数据标准化与归一化

训练前进行标准化或归一化，是为了让不同特征的数值大小比较接近，方便模型学习。

比如一个特征只有 0 到 1，另一个特征有 0 到 10000，如果直接训练，可能会影响模型调整参数的过程，让训练变慢或者不稳定。

标准化一般是让数据的平均值变成 0，标准差变成 1。

归一化一般是把数据变到固定范围，比如 0 到 1。

两者方法不同，但都是为了让数据更适合模型训练。处理数据时还要注意，只用训练集计算需要的统计信息，不能提前使用测试集的信息。

## 13. Batch Normalization

BatchNorm 就是对网络中间的数据进行调整，让数据的数值分布更稳定一些，方便模型训练。

它通常放在卷积层后面、激活函数前面。

训练时，BatchNorm 会根据当前这一批数据的平均值和方差进行调整，同时记录一些统计信息。

测试时，一般使用训练过程中记录下来的统计信息，而不是重新根据测试数据计算。

这样即使测试时一次输入的图片数量不同，模型的预测结果也能相对稳定。

## 14. 分类模型的评价指标

Accuracy 是准确率，表示所有样本中有多少预测正确。

Precision 是精确率，表示模型预测为正类的样本中，有多少是真的正类。

Recall 是召回率，表示所有真正的正类样本中，有多少被模型找出来了。

F1-score 是综合考虑 Precision 和 Recall 的一个指标。

如果数据类别差距很大，只看 Accuracy 可能不准确。

比如 1000 个样本中有 990 个正常样本、10 个异常样本，即使模型全部预测为正常，准确率也有 99%，但实际上一个异常样本都没找出来。

如果不希望把正常样本误判成异常，就应该更关注 Precision；如果不希望漏掉真正的异常，就应该更关注 Recall。

## 15. 参数、超参数与模型泛化

模型参数是模型通过训练自己学到的数值，比如神经网络中的权重和偏置。超参数是我们自己设置的训练条件，比如学习率、Batch Size、网络层数等。泛化能力就是模型面对以前没有见过的数据时，还能不能保持较好的预测效果。模型并不是越复杂越好。网络更深、参数更多，虽然可能学到更复杂的规律，但也更容易过拟合，而且训练起来可能更困难。所以判断一个模型好不好，不能只看它有多少层，还要看它在新数据上的表现。
